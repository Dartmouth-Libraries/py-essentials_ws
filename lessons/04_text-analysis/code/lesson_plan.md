## Objectives

Upon completion of these notebooks and this workshop, participants will be able to:
1. Read in text data in different ways (i.e. as plain-text files or text within csvs)
2. perform basic processing of texts (tokenization, lowering case, stemming, word counts, etc.)
3. perform some basic analysis (named entity recognition, tfidf, similarity analysis)
