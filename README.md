# Python Essentials Workshop Series

## 1. Overview

Interested in learning to program for the first time with Python? Have you started learning Python before but failed to stick with it? Are you excited about the applications AI coding assistants can help you build but feel you need to develop some basic skills first?

If the answer to any of the above is yes, then this workshop series is for you. It is designed for first-time programmers as well as those looking for a refresher of the basics and an overview of Python programming best practices.

## 4. Learning Objectives

Upon completing the lessons offered here, the student will be able to:

+ create functioning Python code in scripts (`.py`) and Jupyter notebooks (`.ipynb`)

+ use different basic Python data types (integers, strings, lists, dictionaries, dataframes)

+ import popular external Python packages to extend their capabilities in the areas of data analysis, visualization, text analysis, and more....

## 7. Getting Started

While participants in our workshop are often given the opportunity to code with Python using the cloud, users who want to continue their learning and build their own Python projects will want to install and set up Python on their own computers.

Even though Python may be the easiest and most versatile programming language for beginners, it can be a headache to set up properly on your own computer. And each computer is different! 

Fortunately, **Research Facilitation** (in Dartmouth Libraries) has set up a tutorial for just such a challenge. To learn how to set up Python on your own personal computer following our recommended method, visit [dartgo.org/python-setup-uv](dartgo.org/python-setup-uv) for instructions on how to set up Python on your computer. Note: 

### Software Installation

If you already have Python setup for your computer that works for you, by all means keep using it. If you don't, we recommend installing the software below using our guide linked to above in the previous section.

#### Required Software

- **Python** (version 3.10 or higher): Download from [python.org](https://www.python.org/downloads/)
- **Visual Studio Code**: Download from [code.visualstudio.com](https://code.visualstudio.com/)
- **uv** (package manager): Install instructions at [astral.sh/uv](https://docs.astral.sh/uv/getting-started/installation/)
